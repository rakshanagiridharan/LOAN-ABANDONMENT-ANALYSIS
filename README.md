# LOAN-ABANDONMENT-ANALYSIS-
I analysed why loan applicants drop off, using SQL, Python (ETL) and Power BI. The biggest bottleneck was verification to approval, where 863 applications sat under review. Splitting non-conversion into abandoned (7.2%) and stalled (31.0%) showed different problems; waits of 12+ days pushed abandonment from 3.1% to 11.6%.
